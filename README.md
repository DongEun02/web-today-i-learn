# Today I Learn

자기소개와 오늘 배운 내용을 기록하는 정적 웹 페이지이다.
HTML, CSS, JavaScript를 분리하여 작성했고, 기본 소개 페이지에 TIL 등록 기능과 간단한 인터랙션을 추가했다.

## 주요 기능

- 자기소개, 기본 정보, 갤러리, 인생 작품, TIL 섹션 구성
- TIL 작성 폼을 통한 새 학습 기록 추가
- 갤러리 이미지 9장을 Grid로 배치
- 갤러리 이미지 클릭 시 확대 모달 표시
- 다크 모드 토글
- 내비게이션 클릭 시 스무스 스크롤 이동
- 현재 보고 있는 섹션에 맞는 내비게이션 강조

## 구현 내용

### 1. TIL 등록 기능

- 날짜, 제목, 내용을 입력한 뒤 등록 버튼을 누르면 새로운 TIL 항목이 목록 상단에 추가된다.
- `submit` 이벤트를 활용해 기본 새로고침 동작을 막고 DOM 요소를 생성해 목록에 삽입했다.

### 2. 갤러리 레이아웃

- CSS Grid를 사용해 3열 갤러리 레이아웃을 구성했다.
- 각 이미지에는 border와 hover 효과를 적용해 시각적으로 구분된다.

### 3. 추가 인터랙션

- 다크 모드 버튼으로 화면 테마를 전환할 수 있다.
- 선택한 테마는 `localStorage`에 저장되어 새로고침 후에도 유지된다.
- 갤러리 이미지를 클릭하면 확대된 이미지를 모달로 볼 수 있다.
- 상단 내비게이션은 클릭 시 해당 섹션으로 부드럽게 이동한다.
